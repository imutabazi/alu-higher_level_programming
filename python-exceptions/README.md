# Python - Exceptions

This repository contains solutions for the ALX tasks focusing on Python exception handling.

## Files
* `0-safe_print_list.py`: Prints x elements of a list safely.
* `1-safe_print_integer.py`: Prints an integer safely.
* `2-safe_print_list_integers.py`: Prints the first x elements of a list, strictly integers.
* `3-safe_print_division.py`: Divides 2 integers and prints the result using finally.
* `4-list_division.py`: Divides two lists element by element safely.
* `5-raise_exception.py`: Raises a TypeError exception.
* `6-raise_exception_msg.py`: Raises a NameError exception with a message.
