===================================
How to Use 1-my_list.py (Doctests)
===================================

This module defines a `MyList` class that inherits from `list`.

First, import `MyList`:

    >>> MyList = __import__('1-my_list').MyList

Create a new instance of `MyList`:

    >>> my_list = MyList()
    >>> my_list
    []

Append some integers:

    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)

Print the list:

    >>> print(my_list)
    [1, 4, 2, 3, 5]

Print the sorted list:

    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]

Verify the original list is not modified:

    >>> print(my_list)
    [1, 4, 2, 3, 5]
